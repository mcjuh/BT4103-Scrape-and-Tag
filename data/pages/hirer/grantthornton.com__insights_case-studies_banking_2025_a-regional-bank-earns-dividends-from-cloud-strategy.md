## Scenario
### Inefficient technology platform
A regional bank needed to improve its core technology platform’s capabilities, scalability and efficiency to accommodate tremendous recent growth.
The bank’s in-house system received annual updates, but its ancillary supporting applications were not updated as regularly. Also, its record purge and other cleanup activities were not conducted regularly.
The bank needed more consistent technology updates and maintenance, especially to help ensure better system resilience and uptime.
## Approach
### A future state plan with delivery
The Grant Thornton team listened to the bank’s unique needs and vision while assessing its cloud strategy, tailoring strategic components to fit. The team delivered a future state definition to move the core banking platform to managed services, rationalize custom applications and secure a vendor to rewrite code for cloud code compilers.
Then, the team produced a program roadmap that included a project plan, charter, infrastructure assessment, application inventory, transition plan, testing plan and migration playbook. For program execution, the team managed collection and refactoring of all of the third-party and custom applications integrated with the core banking platform, contracted vendor support before and after go-live, transitioned core applications to the hosted platform and conducted a lessons learned and sunset review.

## Result
### A successful cloud strategy
The team’s future state definition transitioned computer operations and execution to the hosting provider, eliminating 100% of the work in the computer operation department. The program roadmap’s transition, testing and migration guidance facilitated the successful transition of $16B in assets and account information to the cloud hosting provider.
The program execution transitioned core applications to the hosted platform so that each end-of-day job run is now 20% faster than before.
