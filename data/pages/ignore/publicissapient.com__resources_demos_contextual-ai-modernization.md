What is contextual AI chat?
Contextual AI chat lets developers ask questions about an application and receive answers based on how that specific application works. Slingshot uses the application’s code, capabilities, business rules and dependencies to provide relevant responses.
What can developers ask the chat?
Developers can start with a business goal, such as adding customer self-checkout functionality, and ask what needs to change across the application. They don’t need to start with file names, code paths or detailed technical instructions.
How does selecting a capability improve the response?
Selecting a capability narrows Slingshot’s focus to the files, rules, services and dependencies connected to that part of the application. This makes the response more specific to the change being considered.
How does contextual chat support modernization?
It helps developers understand the current application, identify the changes required and assess downstream impact. This provides a clearer starting point for planning and implementing modernization work.
