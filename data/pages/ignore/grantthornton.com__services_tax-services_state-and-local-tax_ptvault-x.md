## Clarify your tax compliance with data-driven insight
### Real-time data
Authorized users can access real-time data on property taxes, including images of tax bills, receipts and other documents.
### Validated OCR
Our OCR tool extracts data with 98% accuracy — then, its built-in validations further eliminate errors before putting the data into import templates.
### Advanced estimation
Property taxes are sometimes paid 18 months after the liability is incurred, but our estimation tool helps determine future tax liabilities so you can plan to collect tax in advance by monthly installments or at the end of a lease.
### Data analytics integration
The solution database can integrate with most analytical and transformation tools, easily connecting with Microsoft Power BI, Domo, Alteryx, and other tools to create reports and drive informed decisions.

## Frequently asked questions
What are the installation requirements? 
There is no installation required. All you need is a Microsoft Account to log into the web-based application. For access, complete [our contact form](https://gtus365-my.sharepoint.com/personal/raghavendra_shettar_us_gt_com/Documents/2023/May/Ptvault.x/ptvaultx_ShoppingList.v5.2023.04.24.docx#Module8).
Does ptvault.x integrate with other solutions?
Yes, ptvault.x can integrate with data analytics and transformation software products like Microsoft Power BI, Domo and Alteryx. 
How does ptvault.x protect user data? 
The system requires each user to have a separate login and uses Microsoft Azure Active Directory authentication. Each database has parameters around the email addresses used, to safeguard only addresses within the lessor’s domain are allowed access. If a new user is set up with an email address that is not from a permitted domain, data cannot be accessed.
How does ptvault.x protect user data?
There is not a license required per user, so unlimited users on your team can access the ptvault.x without incurring additional license fees.
