###  Sheets 
### Sheets
Sheets contain all workplan-related details and are the foundation of reporting dashboards. Workstream leads will work directly with the Program Level Stakeholders to modify pre-populated functional tasks for each engagement. Similar to any spreadsheet software, sheets will house all project data.
###  Forms 
### Forms
Forms are built like traditional questionnaires and allow users to quickly input newly identified data items into the Transaction Execution Accelerator platform. Through automations forms can be shared with functional leads via email for swift completion.
###  Reports 
### Reports
Reports create a customized summary of select data sources from sheets. Reports allow users to count all open tasks, identify the number of critical activities, consolidate escalating issues and more. The KPMG Transaction Execution Accelerator specialists can work with project leads to create customized reports for each unique deal.
###  Dashboards 
### Dashboards
Dashboards present a holistic view of information summarized from each workplan. Dashboards can be customized to highlight critical Day 1 items, dependency management, workstream timelines, summary of synergy initiatives, etc. The KPMG Transaction Execution Accelerator platform provides clients with pre-populate dashboards that can be modified for each client need.
###  Automations 
### Automations 
Automations enable the platform to run with minimal user interaction. Through select automations, users can create email-generated reports for project statuses, delayed/at risk tasks, and weekly functional summaries. Similar to dashboards, automations are pre-populated and can be modified as requested.
