# Webinar Replay – Are Private Equity GPs Delivering Value for Fees?
Watch the replay now to gain insights into today’s challenging market and higher interest-rate environment, where there’s a growing demand from LPs for deeper insights into the value created by Private Equity GPs.
In today’s challenging market and higher interest-rate environment, there’s a growing demand from LPs for deeper insights into the value created by Private Equity GPs.
Discover the open and non-proprietary [Created Value Attribution (CVA) Framework](https://www.kroll.com/en/insights/publications/valuation/created-value-attribution-on-how-value-created-in-private-equity?elqTrackId=26C895A8662B28314B16E38E8757E1A2&elqTrack=true) developed by Kroll’s [Alternative Asset Advisory](https://www.kroll.com/en/services/alternative-asset-advisory?elqTrackId=B01C6B7825EFB0BD3DFAAC575B3EBA36&elqTrack=true) Team in our recent webinar. This framework provides a comprehensive and intuitive insight into GP-driven operational and strategic value-add, offering greater transparency.
Our Panelists have discussed the following topics: 
  * The fatal flaws of the historical attribution model (the "Value Bridge").
  * The Fix: A refined and robust value attribution framework that can identify and quantify Alpha (i.e., superior organic value creation at the enterprise level), which addresses the question of whether value has been created through “building better businesses”.
  * Insights into private equity value creation from more than 100 entry-to-exit studies, and into the impact on value creation from current interest rate conditions.
