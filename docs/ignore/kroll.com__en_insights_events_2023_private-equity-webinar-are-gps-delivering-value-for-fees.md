# Webinar Replay—Are Private Equity GPs Delivering Value for Fees?
In today’s challenging market conditions, LPs are demanding greater empirical clarity regarding their GP’s value creation and/or preservation competencies. The open, non-proprietary [Created Value Attribution (CVA) Framework](https://www.kroll.com/en/insights/publications/valuation/created-value-attribution-on-how-value-created-in-private-equity) developed by Kroll’s Alternative Asset Advisory team provides a comprehensive yet intuitive look under the hood for greater transparency into GP-driven operational and/or strategic value-add.
Our panelists have discussed the following topics:
  * The fatal flaws of the historical attribution model (the "Value Bridge")
  * The Fix: A refined and robust value attribution framework that can identify and quantify Alpha (i.e., superior organic value creation at the enterprise level), which addresses the question of whether value has been created through “building better businesses”
  * Insights into private equity value creation from almost 100 entry-to-exit studies
  * Potential applications for quantifying value created through specific initiatives, including environmental, social and governance (ESG)
