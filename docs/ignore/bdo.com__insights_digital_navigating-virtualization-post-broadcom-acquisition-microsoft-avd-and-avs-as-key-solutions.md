## Evaluating the Options for Existing VMware Clients
There are many options for existing VMware clients to re-evaluate their current virtualization strategy. Two of the most compelling involve Microsoft AVD (Azure Virtual Desktop) and AVS (Azure VMware Solution). Navigating these modern virtualization options can be both complicated and confusing for organizations. With all the concern regarding Citrix and VMware’s long-term viability, companies today are quickly reviewing options and building alternative plans. Microsoft is offering customers attractive solutions that include virtualization funding opportunities and fixed pricing. Bob Pugh, BDO Azure Lead, comments: “AVS is the fastest and easiest way to migrate your VMware environment to the cloud.” Microsoft’s offering is available today, and for a limited time, you can lock in pricing for up to five years.

## Microsoft Virtualization Solutions: AVD and AVS
Microsoft AVD and AVS offer great options and value. 
AVS is a fully managed service allowing you to run VMware workloads natively on Azure. If you currently run VMware, AVS provides a familiar environment in Azure, enabling the use of existing tools and processes for managing and operating your VMware workloads. With AVS, you can migrate to the cloud with little or no refactoring. It also allows you to scale the environment up or down quickly and easily to meet business demands, improving your disaster recovery and security profile. Even better, AVS is the fastest path to the cloud, where you can innovate on your workloads with more than 200 Azure Services. 
AVD, formerly known as Windows Virtual Desktop, is an Azure desktop and application virtualization service that enables users to access a full Windows desktop experience remotely. It allows organizations to deploy and scale virtualized Windows desktops and apps on Azure, providing a flexible, secure, and cost-effective way to deliver a full Windows experience to employees, regardless of their location. It supports multi-session Windows 10, Windows 11, and Windows Server desktops, allowing multiple users to share the same virtual machine while maintaining personal profiles and settings.
