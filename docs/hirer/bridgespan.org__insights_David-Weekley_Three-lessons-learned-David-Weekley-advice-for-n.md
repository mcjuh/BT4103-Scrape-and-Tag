# Three lessons learned: David Weekley’s advice for new philanthropists 
David Weekley advises others to: 1) back leadership; 2) go big and deep for biggest impact; and 3) go international for more leverage. Of going international, Weekley says it’s challenging—but “in the end, it’s going to be where I’ve had the most impact.” [See More Remarkable Givers](https://www.bridgespan.org/Insights/Library/Remarkable-Givers/Profiles)
